# Work index

Layer: framework core. The entries are project content.

This index points to selected work. It is not a release dashboard and it does not copy state. Each linked checkpoint owns its current state. Follow [delivery task records](../standards/documentation.md#delivery-task-records) before resuming, and check live state before any merge or operation.

## Active deliveries

Every unfinished top-level delivery, including suspended work, with a link to its checkpoint.

## Delivered

Completed deliveries, each linked to its record and named with its pull request.

## Unselected follow-ups

Recorded limitations and ideas that nobody has been assigned. These are not active work.

Cross-domain, tooling and harness changes that belong to no capability keep their records in `docs/work/changes/<change>/`.
