# Answer a question

Layer: framework core. Stages: none; a question is a transient task.

Select the domain owner and load the relevant capability reference. Inspect current code and tests for implementation questions; use approved requirements for intended behavior. Answer the actual question with source pointers, and separate intended, implemented, deployed and unverified facts. Explain a material discrepancy without silently repairing it.

No delivery plan or implementation team is needed for an ordinary question. If tracing is needed, use [investigation](investigation.md). Save a durable correction only when authorized, through [maintain-knowledge](../../.agents/skills/maintain-knowledge/SKILL.md).

For a side question, keep the parent delivery and resume its authorized next action under [session](session.md#continuous-task-routing). No delivery record is created merely to answer.
